# 💙 Cute Birthday Card

Энэ бол зураг, дуугаа өөрөө сольж ашиглах зориулалттай төрсөн өдрийн интерактив мэндчилгээ.

## Зураг солих

`images` хавтас дотор:

- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg

гэсэн нэрээр зургаа байрлуулна.

Өөр зураг нэмэх бол `index.html` дотор gallery хэсгийг хуулж нэмэж болно.

## Дуу солих

`music` хавтас дотор өөрийн MP3 дуугаа:

`birthday.mp3`

гэсэн нэрээр хийнэ.

## Текст солих

`index.html` файлыг Notepad-оор нээгээд:
- мэндчилгээний текст
- нэр
- захиа
- гарын үсэг

зэргийг шууд өөрчилж болно.

## Үнэгүй нийтлэх

GitHub Pages ашиглаж болно.

1. GitHub account үүсгэнэ.
2. New repository үүсгэнэ.
3. Энэ хавтасны бүх файлыг upload хийнэ.
4. Repository → Settings → Pages
5. Deploy from a branch сонгоно.
6. `main` / root сонгоно.
7. Save.

Дараа нь GitHub Pages URL гарна.
